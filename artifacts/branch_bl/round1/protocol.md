# B-L：共享读出失败位置的局部线性可恢复性

2026-09-25。**状态：首轮规划完成；尚未生成数据、拟合或启动实验。**

## 1. 依据与限定问题

[B-S报告](../../reports/branch_bs/FINAL_REPORT.md)中，共享增强头在8、11、12步无噪BA分别为81.531%、84.873%、82.772%，有噪为82.210%、84.717%、82.195%；六项校正区间上界均低于85%。五个拟合时长全部通过，质量审计正常。

[B-R](../../reports/branch_br/FINAL_REPORT.md)只确认5、7、10、13步的专用可恢复性，不能替代这三个失败位置的检验。下一步先区分：这些状态可被专用线性头有效利用，还是本次预定专用流程也无法恢复全部条件。后者仍可能涉及样本量、正则化或编码形式，不能等同于信息消失。

**H-BL1：保持301–305五核心冻结，按本协议为8、11、12步分别训练增强线性头后，三个时长在干净及原1%噪声下的五模型集合平均BA是否全部超过85%？**

每模型每时长有独立的头和标准化器，干净／有噪评价共用该增强头。专用选择使用时长条件资源，不是共享时间读出。集合通过不代表每个模型均通过。

5–15步全部整数时长已被历史实验观察。本轮检验已知失败条件在新图像上的恢复，不称为未见时长泛化。

## 2. 实验臂与冻结条件

核心来源：`artifacts/round6/final/rnn_lr0.001_seed{seed}/final.pt`，seed为301–305。冻结视觉前端、归一化统计、输入层、循环参数及原任务头，使用推断模式。

| 读出 | 拟合输入 | 角色 |
|---|---|---|
| 新专用增强头 | 对应时长干净／带噪末状态，有效权重各半 | 唯一确认性主方法 |
| 新专用干净头 | 对应时长干净末状态 | 干净可读性与增强作用的次要参照 |
| B-S冻结共享增强头与干净头 | 原样加载B-S各模型heads.pkl | 同库配对参照，不重拟合或校准 |

共5模型×3时长×2训练方式=30新头，每头5个C，共150候选。主要评价为5模型×20测试库×3时长=300单元，每单元含四种头的干净预测和10次噪声预测。

同一批测试库另评价原任务头5步和B-N冻结增强头15步的干净／有噪正对照，共200个模型×库×时长锚点单元。首轮不增加其他时长的科学指标、不改变核心或引入非线性头。

## 4. 时序、噪声与拟合

sample/test各4步。test前一次性逐维独立高斯扰动，截断至非负，再运行4步test。绝对标准差读取每模型B-N manifest的sigma_primary，所有时长相同，不按本轮RMS重定标。

噪声流为default_rng(SeedSequence([bank_seed,20000,rep]))；拟合／验证rep=0..3，测试rep=0..9。标准向量跨头、模型、时长配对；模型仅乘自己的固定sigma。干净条件评价一次。

- 输入为对应时长test结束后的64维状态，标签为匹配／不匹配，不增加时间特征。
- 每模型每时长仅用干净拟合末状态拟合一次StandardScaler，对应干净头与增强头共享它。验证、测试及噪声副本不更新统计。
- 干净头每原试次权重1；增强头干净版本0.5，四个噪声版本各0.125。每头总拟合权重8,000、验证权重2,000。副本不计作独立样本。
- 带截距L2逻辑回归，float64，C固定为[0.01,0.1,1,10,100]，无类别权重。沿用已验证Newton-Cholesky流程，tol=1e-7，最多200次，必要时1,000次；所有候选无未解决告警且实际目标梯度∞范数≤1e-6。
- 各头按自身预定验证分布的加权对数损失选C；增强验证同样干净／噪声各半，并列取较小C。保存全部候选、训练／验证分条件BA、损失和梯度。
- 使用默认分类规则；不在测试上改阈值或翻转标签。C落在边界如实记录，不扩网格。不收敛先修复同一数值目标，不作科学反证。

专用头有多组参数和时长专用标准化，且旧B-S头使用不同历史拟合库。新旧差值属于同测试库功能比较，不能独立归因为训练时长覆盖；覆盖因果干预须另做匹配实验。

## 5. 统计终点与裁决

每测试库内先平均每模型10次噪声重复，再平均五模型，形成20个库级集合BA；干净条件直接平均五模型。六项主要指标仅含新专用增强头的3时长×2条件。

每项采用99.166666…%双侧t区间，α=0.05/6，df=19；Bonferroni对应本轮六项合计5%错误额度，依赖库级抽样与t近似。不宣称整个历史自适应项目具有相同整体错误率。

| 裁决 | 质量门槛通过后的条件 |
|---|---|
| 支持H-BL1 | 六项下界全部>85% |
| 排除H-BL1 | 至少一项上界<85% |
| 证据不足 | 其余情况，包括区间恰好触及阈值 |
| 流程异常 | 数据、数值、冻结或质量检查失败，先调查，不作科学裁决 |

保留原始区间；天花板处退化或越界不解释为总体100%准确。推断条件化于固定五核心、一次拟合／验证库和最终头，不覆盖重新拟合或新核心的变异。

次要完整报告四头的所有单模型成绩、新旧头及增强／干净头同库配对差值、各模型最差条件与拟合诊断；未校正区间标为探索性。旧B-S头是否复现低分属于科学结果，不是质量门槛，未复现时不得换数据。主支持仅证明这套流程的绝对功能恢复，不宣称增强必要或唯一机制已定位。

## 6. 质量与实现审计

1. 数量、平衡、隔离、权重审计通过；独立重算150候选验证损失、C选择、scaler来源和梯度。
2. 核心、历史头、归一化统计的磁盘哈希与内存快照前后一致；新头冻结后禁止拟合，scaler与参数不变。
3. test前状态索引3+delay，末状态7+delay。每模型每库每评价时长前32试次核对像素／缓存前向、零扰动续算及清零续算，rtol=atol=1e-5。拟合阶段可检查三个目标时长，测试数据等待冻结。
4. 原任务头5步、B-N增强头15步在两输入条件下的集合BA区间下界均>90%，使用同样99.166667%区间作流程校准。主覆盖声明不扩大为全部质量检查的联合推断。
5. 三主要时长、四头、两输入条件均做test前清零、64次标签置换、64次test数量内末状态行置换。带噪清零先清零再加噪声；噪声置换用rep=0。各条件库／模型／置换平均BA均须在47%–53%，这是校准门槛，不是等效检验。
6. 标签置换流[bank_seed,30000,rep]，状态置换流[bank_seed,40000,rep]，按test数量0..4顺序打乱。保存索引，跨头及时长配对。重新构造全部噪声及续算，复核完整原始预测、负对照和汇总。
7. 复用既有测试，补充本轮时长、300主要单元完整性、30头／150候选、分区隔离与禁止测试拟合等实际风险检查。复用同一模型定义的审计不得称作完全独立的软件复制。

## 7. 由结果决定后续

以下仅为决策原则，尚不是第二轮执行协议。

| 完整结果 | 下一步 |
|---|---|
| 六项均恢复 | 本分支支持结案；优先另立共享训练覆盖干预 |
| 干净恢复、有噪失败 | 根据噪声下训练／验证误差研究局部抗噪限制 |
| 专用头部分条件仍失败 | 根据收敛与训练／验证差距，在样本量、正则化、受限非线性诊断中选择有辨识力的一项，不宣称信息消失 |
| 区间跨阈值 | 根据实际不确定性设计独立确认或有效顺序方案，不边加库边重复普通区间 |
| 集合通过、个体分化 | 完整保留个体结果；所有个体保证或新核心推广另立目标 |

若局部恢复，后续覆盖实验应满足：

- 在同批新拟合／验证图像上重新训练原五时长共享基线，与加入8、11、12步的共享头比较。历史B-S冻结头只作参照，不能代替匹配基线。
- 两臂使用同一个、仅由原五时长干净拟合状态计算的scaler，固定同一C网格、求解流程、噪声单位及总原试次权重。增加时长会重分配时长权重，效应归因限于这个明确的覆盖／权重干预。
- 各臂在自身覆盖时长内等权，总原试次权重1，保留共享干净参照。不得同时改最差时长目标或扩C网格后将效果单独归于覆盖。
- 全部5–15步、两输入条件均评价；既检查失败位置恢复，也检查其余条件退化。预先登记绝对功能、配对改善判据及联合多重比较控制，不能只报有利平均值。
- 这是已知时长集合的新图像确认，不是新时长泛化。若研究真正新的时间范围，需另定范围、任务有效性及留出机制。

若覆盖修复失败，再根据局部读出及每时长训练／验证损失选择目标函数、正则化或共享表达能力实验，不预先机械跑完所有修复。新核心复制、跨外形和持续噪声分别属于独立推广问题。
