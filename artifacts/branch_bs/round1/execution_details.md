# B-S 执行细节（测试生成及留出状态评价之前固定）

完全沿用 protocol.md 的时长、数据、噪声、权重、选择规则和判据。

拟合仅提取5/7/10/13/15步，训练阶段不生成6/8/9/11/12/14步的真实任务状态。每模型两个新头共享同一scaler对象；评价循环中核对所有时长都引用同一个新头对象。旧专用头只作相应五时长的参照。

共享scaler在五时长干净拟合状态的float64合并矩阵上拟合。训练与验证特征先转float64再按该scaler变换；预测使用已保存的scaler。跨时长总权重、跨副本总权重均单独审计。记录每个C的逐时长训练／验证损失和加权BA，但只按预定五时长平均验证损失选C。

先完成50候选及独立训练审计，才能创建全局冻结清单；随后才能生成测试数据。测试阶段禁止拟合，完整评价1100个模型×库×时长单元后再裁决。独立复核所有预测、噪声重复、重置和置换对照，不仅核对均值。

首个模型用于实际吞吐及峰值内存测量；每计算进程1线程，最多2个并行。原始协议、所有候选、时间顺序、失败日志及输入输出哈希保留。
