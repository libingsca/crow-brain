# 首次读取 B-T 测试结果前固定的实现细节

20 库、5 核心、5 延迟、2 头，严格执行 protocol.md。
负对照随机流：每库每次置换使用 SeedSequence([bank_seed,30000,rep]) 产生标签置换，SeedSequence([bank_seed,40000,rep]) 依次对测试数量 b=0..4 分层产生状态行置换。64 次，跨头、延迟和噪声条件共用索引。不进行任何重新拟合；运行时禁止 LogisticRegression.fit 和 StandardScaler.fit。
噪声重复 0..9；主统计先平均重复、再平均五模型、最后对20库计算 t 区间。保存原始预测、重复0的扰动状态、负对照64次预测和评分、原任务头正对照。冻结检查覆盖全部模型 state_dict、两个头的全部 NumPy 参数及磁盘输入。
实现审计每库每模型每延迟取前32试次比较像素前向、缓存前向、测试前零扰动续算、清零续算。容差 rtol=1e-5, atol=1e-5；报告最大误差。浮点批大小可能导致舍入差异，不要求字节相同。
科学结论只在全矩阵和质量审计完成后作出。后续科学轮次仍需依完整结果另行登记。
