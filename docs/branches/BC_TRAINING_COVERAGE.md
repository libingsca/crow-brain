# B-C：增加训练时长覆盖能否修复共享读出？

2026-09-25。**首轮完成：H-BC1被限定排除，按预定判据结案。**

[最终报告](../../reports/branch_bc/FINAL_REPORT.md)。下文保留原规划；执行前原文独立归档在artifacts/branch_bc/round1/protocol.md。

## 1. 依据、干预与范围

B-S共享头在8、11、12步失败；B-L专用增强头六项校正区间下界均>98.66%，证明这些位置具有可恢复的局部线性功能。现在检验增加训练覆盖能否把这些能力纳入同一共享头。

五个核心301–305始终冻结。每模型比较四个新共享头：base_clean、base_aug、expanded_clean、expanded_aug。

- base拟合时长：5、7、10、13、15。
- expanded拟合时长：5、7、8、10、11、12、13、15。
- 全部方法验证时长相同：上述八时长。用共同验证覆盖消除选择规则不同的混杂。base不是历史B-S的逐字复制，而是本轮匹配反事实基线。
- 全部方法的一个共同scaler仅用base五时长的干净拟合状态计算，固定后用于所有时长、四头和所有噪声条件。
- 每方法在自身拟合时长内等权，每原试次跨时长及噪声副本总权重1。因此干预是明确的“训练覆盖及其权重重分配”，不宣称只改变时长支持而保持原时长权重不变。
- 四头均为带截距线性逻辑回归；每模型每方法在所有测试时长使用同一组参数、同一scaler和默认分类规则，不输入delay、不切换头、不校准阈值。

所有5–15步整数时长均已被历史观察。6、9、14步不参与本轮拟合／验证，但只是已知条件的保留检查，不能称为未参与方法开发的新时长。

## 2. 确认性要求与联合判据

H-BC1为以下28项要求的合取：

1. **绝对功能（22项）**：expanded_aug在5至15步全部11个整数时长×干净／原1%噪声两条件的固定五模型集合平均BA均>85%。这包括新增位置、原拟合位置及三个未拟合位置，避免修复局部却破坏其他时长。
2. **实际改善（6项）**：8、11、12步×两输入条件，expanded_aug减本轮base_aug的同库配对BA增益均>2个百分点。2个百分点在观察本轮结果前固定，用于排除仅有微小变化而宣称覆盖修复；不根据本轮基线水平改变门槛。

每测试库先在模型内平均10次噪声重复，再平均五模型；干净评价一次。以20个独立测试库为推断单位，配对差值先在同库形成。28项各用置信水平1−0.05/28=99.82142857%的双侧t区间，df=19，Bonferroni合计错误额度5%，依赖库级抽样及t近似。

质量通过后：所有28项下界严格超过对应门槛支持；任一上界严格低于对应门槛排除；其余证据不足，等于门槛也未决。分别报告绝对功能与配对改善的支持／排除／未决，不能将改善成功误报为全部功能恢复，或把未达到2个百分点说成毫无增益。

85%是功能保持要求，不是不劣于基线：其他时长仍可能明显降分，须完整报告所有22项配对变化，不以平均改善掩盖退化。六项增益使用本轮重训基线，不拼接历史测试成绩。基线是否复现B-S失败不是质量门槛。

本轮范围条件化于固定五核心、一次拟合／验证和所选头；不涵盖新核心、重新拟合变异、生物机制或跨外形数量抽象。普通t区间在天花板处退化或越界如实保存。联合错误额度只针对本轮28项，不声称覆盖整个历史自适应项目。

## 4. 权重、目标与选择

共同scaler在五个base时长的40,000行干净拟合末状态上等权计算，四头共享同一对象。验证／测试不重新标准化；新增时长不改变scaler。

对于含m时长的训练臂，干净头每原试次每时长权重1/m；增强头干净版本0.5/m、四个噪声版本各0.125/m。base的m=5，expanded的m=8。两臂总原试次权重8,000。验证统一m=8，总权重2,000；各clean头按干净验证损失选C，各aug头按50%干净／50%噪声的共同验证损失选C。

固定C=[0.01,0.1,1,10,100]，L2带截距逻辑回归，无类别权重，float64标准化特征；Newton-Cholesky，tol=1e-7，先最多200次、必要时1,000次，所有候选无未解决收敛告警且实际正则化目标梯度∞范数≤1e-6。并列验证损失取较小C。C在边界不扩网格；数值失败须先修复同一目标，不作科学反证。

每候选记录各拟合／验证时长损失和BA；用于诊断，不能事后改为最差时长选参。共同网格和共同验证规则不保证选出同一C，效应解释为整个预定覆盖干预流程，不证明固定C下同样有效。四头干净／带噪表现和单模型最差条件完整报告，干净参照属于次要描述，不构成增强必要性检验。

## 5. 参照与质量门槛

冻结专用增强头在八个开发时长各自原位置作正对照：5、7、10、13步用B-R；8、11、12步用B-L；15步用B-N。另检查原任务头5步。各自在干净／有噪下集合BA的同置信水平区间下界须>90%。专用参照有时长条件资源与历史拟合库，不是参数预算相同的竞争方法。

四新头全部11时长，以及八个专用头对应时长，均保存干净及10次噪声预测；5模型×20库×11时长=1,100存储单元，预计57,200组线性头预测独立复核。

负对照：上述每头／时长／两输入条件进行test前清零、64次标签置换、64次test数量内末状态行错配。噪声清零先清零再加噪声，带噪置换用rep=0；各条件跨库／模型／置换平均BA须在47%–53%。这是流程校准，不是等效证明。标签流[bank_seed,30000,rep]，状态流[bank_seed,40000,rep]，后者按test数量0..4打乱并跨头及时长配对。

必须审计：

- 100候选的共同scaler来源、各臂跨时长／噪声权重、共同验证覆盖、验证损失、C选择与梯度，base拟合矩阵不包含新增时长；三个保留时长无开发状态。
- 核心、归一化统计及旧头的磁盘哈希和内存快照；新头测试前冻结，测试阶段拟合接口禁用，所有时长确实使用同一头与同一scaler。
- test前索引3+delay、末状态7+delay；允许阶段每模型每库每时长前32试次核对像素／缓存前向、零扰动与清零续算，rtol=atol=1e-5。
- 重新构造全部噪声及4步续算，逐项核对全矩阵预测、原任务头、清零、置换索引及评分。独立审计复用模型定义，不声称完全独立软件实现。
- 数据、冻结顺序、正负对照与历史科学产物完整性通过后才裁决。保存所有低分条件和原始失败；不得因单条件失败提前删减矩阵。

## 6. 结果驱动的停止与后续

| 结果 | 判断与后续依据 |
|---|---|
| 28项全部通过 | 限定覆盖修复获支持，结案；若推广优先新核心／重新拟合复制 |
| 目标位置改善，但其他条件跌破85% | 具体覆盖流程存在功能取舍，排除完整修复；检查逐时长训练／验证损失，再决定是否值得检验最差条件目标 |
| 绝对功能通过但增益门槛失败 | 功能达到要求，但覆盖带来预定幅度改善的合取主张未获支持；不能混淆两个结论 |
| 局部专用参照正常而共享训练时长也失败 | 根据训练／验证误差，区分目标权衡、正则化或共享表达限制；不证明共享线性边界不存在 |
| 区间跨阈值 | 依据实际不确定性另定独立确认或有效顺序推断，不反复窥探追加样本 |
| 流程异常 | 先记录并修复实现／数值问题，不判科学假设 |

首轮支持或排除即可结案，不为了轮数继续调参。后续具体科学轮次必须依据完整结果另行登记；不预先机械跑完所有修复。时间、预算、一次优化失败和暂时不显著不是科学停止理由。若以低信息价值停止须列明竞争解释及辨识限制；资源阻塞另报。
