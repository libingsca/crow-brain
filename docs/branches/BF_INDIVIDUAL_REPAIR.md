# B-F：覆盖与条件分组的两因素个体修复实验

2026-09-25，执行前登记。依据最新B-Z完整报告，而非对话中较旧的B-S状态。

## 依据和问题

B-Z五次独立重拟合后，固定五模型平均22条件全部>85%，但301/302的15步无噪、304的9步无噪、305的14步无噪短板稳定存在。前两条件已用于拟合，后两未用于拟合；不能统称为抽样波动或覆盖不足。B-L已验证8/11/12局部可读，B-C覆盖干预与B-W最差时长目标也已完成，不重复它们。

本轮用同批新数据的2×2设计区分两种可干预因素：训练覆盖8→10时长（增加9、14）与平滑最差损失的分组方式（每时长混合干净／噪声→每时长分别计算干净／噪声组）。不改变核心、线性头容量、scaler、温度、正则化网格或总原试次权重。

## 固定四臂

- base_mix：八时长[5,7,8,10,11,12,13,15]，每时长50%干净+50%噪声为一组。
- base_split：同八时长，但干净、噪声分别成组，共16组。
- cover_mix：加入9、14后的十时长[5,7,8,9,10,11,12,13,14,15]，每时长混合组。
- cover_split：同十时长，分开干净／噪声，共20组；这是主要候选。

各组内对数损失按权重平均。四方法均最小化0.05*log(mean(exp(L_group/0.05))) + ||beta||²/(2*C*8000)，截距不正则。mix组是干净0.5、四噪声各0.125；split为独立干净组与四噪声等权平均组，外层组等基础权重，故干净／噪声仍各占50%基础权重。split改变风险聚合，不改变每原试次总权重。覆盖干预同时改变时长支持与基础权重，不能归因于纯支持变化。

五核心301–305冻结，sample/test各4步，末状态64维。每模型四头共享scaler，仅原五时长[5,7,10,13,15]的干净拟合状态等权拟合；每方法跨全部测试时长固定一组线性参数及标准化，不输入或按delay切换。核心状态可隐含时间。

C=[.01,.1,1,10,100]，零初始化float64阻尼Newton+Armijo，tol梯度∞≤1e-7，最多200后延至1000步；独立审计≤1e-6。四臂统一按十时长×两输入条件的最大验证组对数损失选C，并列较小C。base的验证因此包含9、14；它是本轮匹配基线，不是B-Z原流程的逐字复制。结论针对包括选参的完整干预流程，不承诺固定C因果效果。6步不参与拟合和验证；所有时长均已被历史观察，不声称新时长泛化。
