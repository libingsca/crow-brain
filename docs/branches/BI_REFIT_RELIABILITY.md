# B-I：固定核心下独立重拟合的全条件恢复可靠性

2026-09-26。状态：**计划，未执行**。承接[研究规划v0.3](../RESEARCH_ROADMAP_v0.3.md)。本文件是首轮方案；执行开始前须原样复制到独立工件目录作为不可变协议，并冻结代码和配置。后续改动若影响科学条件，必须在数据生成前另行记录。

## 1. 问题、假设和统计单位

B-H给出了第二轮固定新拟合头的全110条件支持，最小下界85.020874%，但没有估计重拟合成功率。第三轮对冻结头增加新测试库不算独立拟合。五核心301–305固定，不在本轮重新训练核心。

一次“拟合批次”指抽取一套新fit/validation数据，用既定流程为五个固定核心各拟合一个eleven头。令该批次成功事件E为五核心×11时长×干净／噪声的全部110个真实测试BA均>0.85。

主研究量p=P(E)，随机性来自独立拟合数据及预定训练噪声流程，条件化于这五个核心和固定任务生成机制。

**H-BI：p≥0.80。** 0.80是此新研究问题的最低实用可靠性门槛，不是单条件BA阈值，也不是历史结论。报告区间与失败风险，不将达到80%包装成几乎总能成功。

首轮K=6个独立拟合批次，统计单位为批次；五核心不是五个独立拟合样本，同一头的40个测试库更不是40次重新拟合。批次内五核心共享数据以保持配对，批次之间不共享图像或测试库。

## 2. 固定拟合方法

- 核心：现有301–305检查点及编码器完全冻结、eval模式；不改变核心参数或结构。
- 唯一新候选：B-H第二轮eleven流程，全部整数时长5–15，22个干净／噪声组；C=10000，tau=0.005。
- 每原试次总基础权重1，干净与噪声各50%，四训练噪声重复等权；各时长基础权重相同，正则化N=8000。
- 目标为tau×log(mean(exp(L_group/tau))) + ||beta||²/(2×C×8000)，截距不正则。共享固定线性头，无时长标签或按时长切换头。
- 每个模型、每批scaler重新用[5,7,10,13,15]的干净拟合末状态拟合；不能沿用B-H旧scaler。原sigma绝对定义不变。
- 零初始化float64 Newton+Armijo，梯度∞≤1e-7、最多1000步；独立审计≤1e-6。无超参数选择、验证集挑选或失败种子剔除。validation只作诊断。
- 30个新头全部完成拟合、质量审计并冻结后，才生成任何本轮测试图像。拟合数值失败先修复，不能替换该批种子或记为科学失败。

旧B-H头和失败位置只作开发依据，不把旧模型的测试结果混入新可靠性统计。训练状态可从像素重建，不需永久保存所有中间缓存。

## 4. 两层不确定性和跨轮错误额度

### 4.1 跨轮预算

B-I第r个确认／诊断轮使用alpha_r=0.05/2^r，r从1开始，所有B-I轮之和≤0.05。每轮一半分给库级测量、一半分给批次级成功率。因此首轮alpha_1=.025，alpha_measure=.0125，alpha_rate=.0125。

这些额度针对新的B-I主可靠性主张，不追溯涵盖历史所有实验或新的机制分支。默认后续轮使用新独立批次，单独计算；不将观察后选定的累积样本数直接代入普通固定样本区间。改变累计方式需要先登记有效的序贯方案。

### 4.2 库级测量：将每批分成S/F/U

每固定模型、时长与输入条件先在库内平均10噪声重复，再以40库计算BA均值和双侧t区间，df39。首轮共有K×110=660项，单项置信度为1−alpha_measure/660；Bonferroni保护全部6批的条件区间。

- **确定成功S**：该批全部110项下界严格>0.85。
- **确定失败F**：该批至少一项上界严格<0.85。
- **未决U**：其余情况。

必须完整评价所有条件再分类，不根据最差点估计直接二分。各批测试库彼此独立；t近似及图像去重可能引入的有限依赖须明确，不把近似覆盖当作无条件精确保证。若数据分布／生成器检查揭示近似不适用，应先修复推断方案并留痕。

### 4.3 批次级概率：未决的保守处理

设K=S+F+U，真实成功数位于[S,S+U]。用精确二项Clopper–Pearson界：

- L=0（S=0）；否则 L=BetaQuantile(alpha_rate/2; S, K−S+1)。
- V=1（S+U=K）；否则 V=BetaQuantile(1−alpha_rate/2; S+U+1, K−S−U)。

报告p区间[L,V]。在独立同分布拟合批次与测量覆盖事件成立的条件下，区间覆盖错误额度不超过alpha_measure+alpha_rate；所有轮次再由预定alpha花费控制。不把未决项填成成功率点估计；报告确定成功比例S/K、可能成功比例(S+U)/K以及对应区间。

独立性和p的含义条件化于固定算法、核心及生成分布，不外推核心总体。批次种子为可复现伪随机实现；若出现流程依赖、数据复用或选择性替换，必须在解释前修复，不能照用二项模型。

### 4.4 首轮的能力边界

K=6即便全部确定成功，首轮L也仅约0.4292，不能支持p≥0.80。首轮是诊断和负向筛查；例如6批均确定失败时V约0.5708，可排除p≥0.80。

在首轮同等预算下，即便全成功也至少需23个独立批次才可能使L>0.80；若下一轮按r=2预算、从全新批次确认，全成功时也至少需26批。这只是最乐观的数学下限，不是第二轮预定样本量，更不保证真实数据有足够统计功效。第二轮必须根据第一轮S/F/U及方差规划样本量，不能先宣称“小规模重复证明稳定”。

## 5. 首轮诊断输出

完整保留每批每核心每条件的BA、区间及原始预测，同时报告：

1. 全批S/F/U及p的保守区间；每批最差点估计和最小区间下界。
2. 失败／未决的模型、时长和输入条件分布，特别标明301/9/noise等历史薄弱项；不删除其他失败。
3. 独立拟合间的系数范数、读出方向相似性及训练／验证组损失，帮助区分边界波动与一致短板。这些是描述性诊断，不自动构成机制证据。
4. 如给出跨批平均BA，必须与主p结论分开，不能用平均性能掩盖某批整体失败。

## 6. 质量门槛与独立审计

- 数据：数量对象、像素重复、sample/test不同图、标签与配对平衡、split隔离、所有随机流核对。
- 拟合：输入和旧核心哈希、scaler来源、每原试次权重、22组风险、目标与梯度独立复算，保存全部优化轨迹；核心和原参考头不变。
- 正对照：沿用八专用时长参考头及原任务5步头；每批分别报告18个五模型平均条件，以双侧99%库级t区间下界>90%作为流程门槛。质量区间不并入主可靠性结论，也不声称所有质量检查联合99%覆盖。
- 负对照：每批、每候选时长／输入，以及专用参考对应条件，清零、64标签置换、64test数量内状态错配的库和模型平均均值须47–53%。清零后再加噪，置换噪声用rep0，沿用既定流程。通过不是等效证明。
- 独立从像素重建全部时长和噪声预测、原头预测、reset与置换；测试期间禁止拟合，参数前后及磁盘哈希一致。
- 第二套聚合过程重算660个条件区间、S/F/U和Beta概率界；用有已知答案的统计单元检查验证样本单位、未决处理、边界及alpha花费。

质量门槛未通过时不裁决主假设，先按原目标修复并保留全部日志。全部科学单元完成后才分析，不省略已经出现失败的批次或条件。

## 7. 首轮后的条件性决策与停止

主判据：L>0.80支持H-BI；V<0.80限定排除；其余未决。边界相等按未决。支持或排除均可关闭该限定分支，随后若启动机制或新核心分支需另立新问题和协议。

若未决：

- U占主导时，优先解决库级精度；下一轮的测试库数、批次数和误差预算依据当前完整方差与区间制定。冻结旧头补测如有必要，须单独注册如何控制测量误差，不能未经设计并入主p估计。
- 批次已大多可分类、但p区间仍宽时，增加独立拟合数量；默认新批次另作确认并使用下轮alpha预算。
- 明确失败集中于少数条件时，报告其重复性，依据结果制定针对性诊断；不得换掉失败核心、放宽85%或80%阈值后继续称为同一假设成功。

不因K=6完成而自动结案；没有证伪也没有支持时，只有能具体说明继续此路线的信息价值极低才停止，必须列出残余解释、可行干预及其无法区分的原因。预算、时间、存储或一次数值失败本身不是科学停止依据。
