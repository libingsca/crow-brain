# 下一步方向 B-T：抗噪读出是否同时获得时间泛化？

2026-09-24。**状态：首轮完成，H-BT1 在限定范围内被证伪，按预定规则结案。**依据 [B 报告](../../reports/branch_b/FINAL_REPORT.md) 与 [B-N 报告](../../reports/branch_bn/FINAL_REPORT.md)；两个已完成分支的结论保持原有范围。

执行结论：质量审计全部通过；八项迁移条件的99.375%区间上界均低于85%，最高65.270%。15步增强头无噪／有噪仍为97.850%／97.040%。详见 [结案报告](../../reports/branch_bt/FINAL_REPORT.md) 和 [停止决定](../decisions/branch_bt/BT001_STOP.md)。下文保留原规划；未改动的执行前协议见 `artifacts/branch_bt/round1/protocol.md`。没有启动第二轮或共享头训练。

## 1. 为什么优先做这个问题

B 发现：按同一时间拟合的读出可以很好地使用状态，但5步拟合的匹配头迁移到15步时平均 BA 只有48.225%。B-N 随后发现：在15步上，仅改变读出的训练状态就能将三个既有敏感模型的带噪 BA 从58.12%提升至97.56%，核心不需要更新。

**B 的时间迁移失败发生在噪声增强之前，不能直接当作 B-N 新读出的性质。**新读出可能利用了对时间变化也较稳定的特征；也可能仍然只是一个15步专用头。这两种情况尚未检验。

因此，优先检查已有能力，再决定是否训练共享头。首轮零重新拟合，以明确的新延迟任务检验这个未知点。

| 方向 | 本阶段优先级 | 理由 |
|---|---|---|
| B-T：已有抗噪头的跨时间迁移 | 第一优先 | 直接检验尚缺失的功能，能复用现有权重，并区分是否还需要时间相关读出 |
| 新核心训练种子复制 | 推广结论前必需 | 现有窄区间只覆盖固定模型上的输入采样；不能替代模型群体复制。待候选方法及其时间适用范围明确后，复制问题会更清楚 |
| 持续噪声、相关噪声或干扰刺激 | 保留 | 目前只验证测试前一次性状态扰动；新噪声过程会同时改变问题，需要单独界定 |
| 多外形数量抽象与生物机制拟合 | 独立方向 | 时间／噪声泛化不解除感知捷径或 NCL 机制不可识别问题；不与本轮混在一起解释 |

这里不预设“噪声增强必然带来时间泛化”，也不把已有五个模型上的进一步优化当作新模型复制。

## 2. 首轮限定假设 H-BT1

**在五个既有固定核心上，各自仅使用一个在15步训练的 B-N 增强线性头，不输入外部时长、不切换读出或标准化，是否能在5、7、10、13步的干净及主噪声条件下保持有用表现？**

“一个头”指每个模型在所有时长上使用同一组读出参数，不是让五个不同核心共享一组参数。

有用表现定义为：**每个预定新延迟 × 噪声条件，五个固定模型集合的平均 BA 均 >0.85**。这是对四个离散时长、两种扰动条件的八项要求，不是对所有时长的连续保证。单个模型可能失败，因此须同时呈现全部模型，不能只展示集合平均。

新时长指“未用于这些 B-N 头的拟合和验证”。5步曾用于核心训练；10步也曾在 B 的其他诊断中出现。因此不宣称这些时长对研究者、整个项目或原核心完全未知。

B-N 的干净训练头作为配对参照，帮助判断时间泛化是否与噪声增强共同出现。它不改变 H-BT1 的绝对功能判据：若两个头都能泛化，应承认无法据本轮说噪声增强独有地造成了时间泛化。

## 3. 第一轮协议：冻结已有头的时间扫描

### 不变部分

- 五个普通核心301–305全部保留，主集合改为预先指定的全部五个，而非继续沿用噪声敏感三模型子集。本轮研究的是时间迁移。
- 核心来自 `artifacts/round6/final/rnn_lr0.001_seed{seed}/final.pt`。
- 两个比较头来自 `artifacts/branch_bn/round1/seed{seed}/heads.pkl` 的 `clean`、`aug` 条目。加载后只预测；不重新拟合、不选C、不重新校准均值／方差。
- 视觉前端、归一化统计、输入层、循环权重、线性系数与标准化参数全部冻结。保存磁盘哈希及内存参数前后比较。
- 每个模型的两个头均跨所有延迟原样使用。禁止按时长换头、按时长重新标准化或加入显式 delay 输入；核心状态自身可能携带时间信息，不声称时间信息被移除。

### 条件与数据

- sample/test 各4步；延迟集合为 **{5,7,10,13,15}**。15步是原任务锚点，前四个是主要迁移条件。
- 噪声为无扰动和 **B-N 原定义的1%噪声**：每模型绝对标准差直接读取 B-N manifest 的 `sigma_primary`，跨时长保持相同；测试输入前加逐维独立高斯噪声并截断到非负域，再运行4步测试动力学。
- 首轮不增加持续噪声、外形变化、容量变化或更长延迟外推，以免把多个未知混为一谈。
- 20个新 mixed 图像库，seed=920100..920119；每库每数量200张，共20,000张。每库2,000个按原规则平衡的数量对。
- 数量对随机流为 seed+10000；噪声使用 `SeedSequence([seed,20000,replicate])`，replicate=0..9。相同标准正态向量跨头与跨时长配对使用，再按每模型预定幅度缩放。干净条件只评价一次。
- 图像库相互独立；检查与 B 的四库、B-N 的22库没有像素重复，并检查数量、标签平衡和 sample/test 不同图像。
- 所有时长、两个头、全部模型共用同一批图像及数量对。报告所有条件，不根据曲线挑选“最好泛化区间”。

### 对照与实现审计

1. 15步增强头干净／带噪表现须重现其有用性，集合平均 BA 区间下界均 >0.90。与旧点估计不完全相同不算失败；新图像输入存在抽样差异。
2. 原核心原任务头在5步干净／带噪条件下作为正对照，集合平均 BA 区间下界均 >0.90。该正对照不参与主要头的时长切换。
3. 对各主要条件，清零测试前状态并评价两个冻结头；带噪条件在清零后施加同样定义的噪声。
4. 对各主要条件做64次独立测试标签置换、64次按测试数量分层的末状态行置换，先在库内平均。噪声条件采用replicate=0作上述直接负对照；不把单次随机训练标签拟合当作“必须恰好随机”的判据。
5. 检查不同 delay 下的测试前索引为 `3+delay`，且像素／缓存前向、零噪声续算、清零续算一致；不能复用 B-N 中硬编码15步的状态提取而声称完成了时间扫描。
6. 不调用任何拟合或参数选择流程。冻结对象既检查磁盘文件，也检查内存中的模型参数、标准化参数和读出系数，防止意外校准不落盘而逃过哈希检查。

## 4. 主要统计与科学判据

每个图像库内，先对每个模型的10个噪声重复平均，再对五个预定模型平均。由此，每个主要条件得到20个独立图像库上的集合平均 BA。

八个主要条件分别计算 **99.375% 双侧 t 区间**，即每项错误额度0.05/8；Bonferroni 合计覆盖至少95%，限于相应抽样与近似假设。推断只针对固定五模型和固定头上的新图像／扰动采样，不包括新训练种子、重新拟合头或连续时间域。

主要汇总之外，完整呈现5模型×5时长×2扰动条件的成绩、每个模型的最低成绩、干净头对增强头的配对差异。平均改进、曲线斜率或最优时长都不替代八项主判据。

质量门槛：输入和冻结审计通过；15步增强头、5步原任务头的四个正对照条件下界分别 >0.90（使用同样99.375%区间作流程检查）；两个冻结头在每个主要条件上的清零、标签置换、状态错配总体均值均在[0.47,0.53]。这些是流程校准，不是统计等效声明。任何异常先排查，不能直接裁决迁移假设。

- **支持 H-BT1**：质量通过，八个主要 BA 区间下界全部 >0.85。
- **排除这套固定头的有用跨时长迁移**：质量通过，至少一个主要区间上界 <0.85。只排除已指定的头和有限条件要求，不排除重新训练共享头的可能性。
- 其余为证据不足，包括恰好在阈值上。不能追加几个库后重复普通区间直到显著，也不能把失败条件从主集合移走。

该判据验证的是功能充分性，不单独证明噪声增强的必要性或独有贡献。若增强头和干净头均通过，应如实报告；若仅增强头通过，配对差异先按预定次要分析呈现，不能把未作多重控制的单点差异包装成新的确认性机制发现。

## 5. 结果如何决定后续方向

以下是决策原则，**不是已经排定的第二轮协议**：

| 首轮观测 | 可得结论 | 后续可选方向 |
|---|---|---|
| 增强头在八项条件均通过 | 已有单时长训练头具备指定跨时长功能，H-BT1可按支持结案 | 若需要向模型群体推广，优先新核心种子复制；没有必要仅为了增加轮数再训练共享头 |
| 两种头都通过 | 时间泛化能力存在，但不能归功于噪声增强独有作用 | 检查为何旧B的头不同，或直接进入新种子复制；不重复制造“增强胜出” |
| 中间时长可用，5步明显失败，或出现局部性能谷 | 时间相关边界不匹配是候选，不能用两端点表现推定中间能力 | 根据实际失败时长，下一轮才登记多时长共享头或受限时间校准比较；选定拟合／验证时长后留出新的测试时长和图像 |
| 15步锚点可用，多个新时长失败 | 固定头的时间通用性被限定排除 | 若继续寻找修复，应另立共享头假设，先验证失败时长上条件专用头能否读出信息，不立即重训核心 |
| 干净能迁移、带噪不能 | 时间泛化与噪声稳健性没有自动组合 | 下一轮才设计跨时长噪声增强，统一原始噪声单位，并检验新时长留出 |
| 锚点或负对照异常／区间跨阈值 | 暂不能作科学结论 | 先根据具体误差做实现、采样或不确定性审计，再登记下一轮 |

若进入共享头训练，必须保持每原试次的总权重、标准化规则和选择机会可比较；共享头不得借助时长标签选择不同标准化或读出。条件专用头有额外时长信息与多个参数集，应作为信息可用性的参照，不能冒充容量／资源完全匹配的竞争模型。具体训练时长、混合权重和主要终点由本轮完整结果决定。

## 6. 新种子复制与停止边界

已有 B、B-N 及拟议 B-T 都复用五个核心。更多新图像不能补足这个限制。任何“普遍适用”“普通RNN通常如此”或面向架构优劣的结论，都必须用未参与这些发现的新核心训练种子及独立拟合／验证／测试进行确认；不能只保留训练成功或迁移成功的种子。

本次首先解决既有方法的时间适用范围，未提前承诺一个无条件的“核心总能被某种头修复”的存在性目标。H-BT1 若获支持或被排除，可按相应条件结案；修复方法或群体复制属于需要重新界定的假设。

继承执行要求：启动后持续到限定假设得到支持／被排除，或有具体证据说明进一步实验的信息价值极低。除首轮外，每轮必须依据上一轮完整结果先写协议再执行。时间、轮数、一次优化／实现失败或暂时不显著都不能冒充科学停止理由；资源阻塞要如实记录。低价值判断须列出剩余竞争解释、可行干预及为什么已有条件无法有效区分它们。

执行产物隔离到 `artifacts/branch_bt/`、`reports/branch_bt/`、`docs/decisions/branch_bt/`；保留每轮协议、输入／代码哈希、原始预测、全部失败和停止决定。CPU每任务1线程，最多两个计算任务并行，先测小批吞吐再估算资源。
