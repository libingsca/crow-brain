# B-Z：独立重拟合重复实验

2026-09-25，本轮已完成。平均功能假设：支持；个体最差表现假设：排除。

[最终报告](../../reports/branch_bz/FINAL_REPORT.md)。以下保留原设计；执行前原文另存artifacts/branch_bz/protocol.md。

B-W在固定五核心平均上22个条件全部超过85%，但四个模型仍有低于85%的条件。本轮检验这种平均功能是否可重复，以及个体最差表现；不修改B-W的严格增益判据或其结论。

## 固定设计

5个独立批次，每批同一对新拟合／验证图像库用于核心301–305。每核心只比较mean_aug与worst_aug，保留B-W训练算法：八时长[5,7,8,10,11,12,13,15]；scaler仅原五时长干净拟合状态；每原试次总权重1；干净0.5加4个噪声各0.125；tau=0.05；C=[.01,.1,1,10,100]；最大验证组对数损失选C，并列较小C。同一Newton解析梯度／Hessian、1e-7收敛、独立审计梯度<=1e-6。核心、噪声sigma和专用参照均冻结。14步不用于拟合／验证。不增加干净训练臂，因为本轮问题是增强流程的重拟合稳定性。

每批拟合5,000图像／8,000试次，验证5,000图像／2,000试次；批次r=1..5种子980000+1000r+1/+2。全部50头、250候选先完成独立审计及冻结，随后才生成任何B-Z测试数据。每批4个独立测试库，种子980000+1000r+100..103，每库1,000图像／2,000均衡试次。共70,000张新图像，批间及相对历史224,000张留存图像像素无重复。检查连通域数量、配对平衡及标签。没有未见过的时长，推断仍条件化于固定五核心。

每头测试5–15步，干净一次、相同定义噪声10次；每批模型共享相同测试库。随机噪声及64次标签置换、test数量分层状态错配、清零控制完全继承B-W。记录完整候选、预测和噪声重算审计。专用参照与原任务5步参照为流程正对照。

## 统计单位和事先判据

独立单位是5个训练／验证／测试批次，不是20个测试库，也不是25个模型。每批先在每模型每库内平均10次噪声，再平均该批4库；记S[r,model,delay,condition,method]。干净同样平均4库。

两组确认性问题，共27项，使用双侧t区间，df=4，confidence=1−0.05/27=99.81481481%；27项Bonferroni联合错误额度5%。5批样本少，正态近似是限制；保存全部批次，不将窄库内区间冒充拟合不确定性。

- H-BZ-panel：worst_aug每批平均五模型，22个时长×噪声条件跨批均值的区间下界均>85%。目标是新拟合数据下的期望五模型平均表现，不是每批必然通过。
- H-BZ-individual：对每批每核心取22条件中的最小S，再以5批为样本求该核心期望最差表现的区间；五核心下界均>85%。这是有限4库观测最小值的期望，包含选择最小值带来的向下偏差；不能当作精确总体最小准确率。五模型是固定面板，不抽样代表所有核心。

每项下界>85%为支持，上界<85%为排除，否则未决（等号亦未决）。每组全部支持才支持；任何一项排除则该组排除，否则该组未决。两组单独报告，不用个体失败抹去平均成功。

14／15步worst−mean的四项增益仅描述：给出跨批均值、5批原值和未校正95%区间，不用于确认性通过，不将>0替换B-W的>2pp成功要求。报告两方法全部批次／核心／时长，B-W各核心既有最差条件在本轮的值与排名、每批最差条件及重复次数，均为描述性稳定性诊断，不挑选有利批次。

质量：每批平均的参照BA均>90%，全部批次合并正对照99.8148%区间下界>90%；各批各头／条件三类负对照均值在47–53%。任一质量失败则科学裁决无效，先检查原因。训练／预测、顺序、数据及旧科学文件哈希审计全部通过后才出结论。
