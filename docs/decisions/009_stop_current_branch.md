# Decision 009：本次自适应实验闭环的停止依据

日期：2026-09-24。用户要求：每轮从上轮结果制定，直至假设获得支持／被证伪，或具体判断继续价值极低。没有以时间、轮数或一次训练失败作为停止理由。

## 已判定的有限问题

1. **现象充分性得到支持**：普通端到端 RNN 在当前圆点任务中可形成独立试次、跨面积／范围协议的内部峰形调谐；Round 3 的新训练种子提供这项证据。短延迟任务的功能充分性亦在 Round 4 校准诊断和 Round 6 新普通核心中表现出来。并非所有实现都有同样比例的峰形单元，不宣称唯一机制或完整生物复现。
2. **现有模型的有用跨外形泛化被排除**：Round 5 的预定主指标上界 .527 < .65。
3. **限定 H2-core 被排除**：Round 6 E/I 与普通核心共享前端、相同初始有效权重和公平调参预算；主指标配对区间完全位于 ±.05 内，E/I 本身上界 .513 < .65。输出符号约束确实生效，非空对照。

## 为什么此时不继续堆结构

圆点内任务已近上限，且简单边界统计代理也能解决；数量外形迁移和训练外延迟仍失败。最小、公平的 E/I 核心对照没有补上缺口。继续在同一 renderer 上搜索 motif、压缩或组合，更可能优化未被区分的视觉策略，不能增加对乌鸦神经机制的辨识度。具体主问题已判定，重复调参的边际信息价值低；停止的是这条实验分支，不是整个鸟类认知研究。

## 明确保留的未知

- 未证实或证伪真实 NCL 的 E/I 因果机制、吸引子或 canonical circuit。
- 未排除改变视觉学习、细胞比例、时间常数、训练分布或更大预算后的 E/I 模型优势。
- 未开展 Area X motif、压缩、跨认知任务迁移；没有足够证据触发这些阶段。
- Long-delay 的小幅 E/I 均值差是探索性，不包装成确认性增益或绝对无效。

## 若未来重启，应解决什么新问题

先建立跨外形／大小／纹理／时长的训练与验证协议，分开感知泛化和记忆机制；或取得能区分前馈与循环解释的生物干预／更完整试次数据，并指定可预测观测量。新证据或新可辨识问题出现前，不沿当前圆点基准继续增加架构复杂度。这是重启条件，不是本次停止前漏做的既定实验。

所有 39 次梯度训练运行均保留（含 6 次未学会任务的开发运行）；5 个固定随机网络最终对照、校准诊断和 shape 控制另计。10 次评估渲染断言失败已从原权重统一恢复，原失败记录未删除。9 项测试通过。
