# B-I 第二轮：冻结六批读出头的联合精度补测

## 决策依据与问题保持
首轮完整评价与独立审计后，S=0/F=0/U=6，概率界[0,1]。21个未决条件全部在核心301，12项为15步clean/noise。其余639项已有首轮联合区间支持。现阶段主要瓶颈是测量精度，不能将六个未决批次当作失败，也不能停止。
本轮不增加拟合样本，不重拟合任何模型或scaler。K固定为首轮六个独立拟合批次，主假设仍为p≥.80，单条件仍须真实BA>.85。

## 新鲜共同测试库与样本量
640个全新库，种子1240100–1240739；每库1000图（数量2–6各200）、2000平衡试次。配对seed+10000；噪声/两类置换流沿用[seed,20000/30000/40000,rep]，10噪声、64置换。与全部914000张历史留存图及本轮图像去重，保持同数量拒绝重采样并留痕。
本轮共同精度库同时测量六个冻结301头，避免重复生成图像和计算相同核心状态。此为对首轮测量设计的明确修订：首轮六批测试库仍互不共享，本轮补测允许共享。每个头的单项t区间仍以640个独立库为单位；跨头相关由Bonferroni处理，不要求这些区间或S/F/U观测相互独立。六批真实成功事件的独立抽样来自原先各自独立的训练数据，而非测试库。本轮不把共同库算作新拟合样本。
按首轮未决项库方差，640库及21项校正后，预计clean区间半宽约0.09–0.11百分点、noise约0.04–0.08百分点，足以区分多数当前点估计与85%的距离，但不保证全部分类。不得根据本轮部分结果增减库数。

## 条件与对照
主要补测条件精确列于config.json的targets：首轮21项未决条件。计算时统一执行延迟[5,9,10,11,15]、干净与10噪声；只将预选21项用于更新主证据，其余为描述性诊断，不推翻或挑选首轮区间。
核心301及其六个候选头冻结，测试前复制并核对；301的历史ref5/ref15和original5作为本轮正对照，6项99%双侧库级t下界须>.90。由于本轮只新测301，不使用五核心平均冒充本轮对照；原首轮每批18个五核心平均对照继续留存。候选头所有本轮时长/输入及ref5/ref15的reset、64标签置换、64数量内状态错配平均均须.47–.53。
禁止测试期fit；所有原始预测、图像、配对及完整每库置换索引保存。空间估算：640份图像和置换约416MiB，紧凑预测及报告预留150MiB，现有可用约949MiB；无需删除旧工件。

## 联合推断与停止
r=2的alpha总额=.0125，measurement=.00625，rate=.00625。21个选定条件使用全新640库计算双侧t区间（df639），每项alpha=.00625/21；噪声先在库内平均。新库不与首轮40库合并。
对每个原批次的110项：首轮639个已支持条件保留原区间；21个未决条件以本轮独立新库区间替换。全部110下界>.85为S，任一上界<.85为F，否则U。有效性通过首轮测量事件与本轮测量事件的交集保证，累计测量错误额≤.0125+.00625。本轮预选目标基于首轮完整结果；条件于既有头和选择，新库测量仍有效。
K固定6，没有依结果改变拟合样本数或筛掉任何批次。以新S/F/U用Clopper–Pearson的alpha_rate=.00625重新构造保守概率界；复用相同六个潜在成功事件不冒充新样本。累计测量误差及本轮概率误差≤.025；保守地同时计入首轮已使用的概率额度后，前两轮总额≤.0375，遵守原alpha花费。共享测量产生的依赖不影响“真实成功数在[S,S+U]”与二项区间事件的联合界证明。
本轮L>.8支持，V<.8排除；否则仍未决，依据完整新结果决定下一轮。若U已大幅减少但p界仍宽，下一轮增加新独立拟合批次；若仍主要为精度问题，按新方差针对冻结头规划。不得以本轮640库完成作为停止理由。
