# B-I 第三轮：独立重拟合的核心301必要条件检验

## 根据第二轮结果制定
第二轮六个原批次为S=2/F=1/U=3；主要残余测量不确定性为批次1、3、5的301/15/clean，批次2已由15步clean/noise确认失败。即便消除六批全部U，也不能用固定K=6裁决p≥.80：已有两个S阻止排除，已有一个F且样本很少阻止支持。因此增加独立拟合样本，而非继续只提高这六批的精度。

## 必要条件与原假设的逻辑桥梁
令A表示某独立拟合的核心301在全部整数时长5–15、clean/noise共22项的真实BA均>.85，q=P(A)。原五核心110项事件E蕴含A，因此p≤q。该关系不依赖其他核心是否新拟合或新测试。
本轮仅执行原固定算法的301分量，使用K=96套全新独立fit/validation数据。其训练不读取其他核心的拟合结果，完全等同于完整五核心流程中的301部分。本轮S/F/U只针对A，不冒充五核心事件E。若q上界<.80，原H-BI即被限定排除；若q下界>.80，仅支持必要门槛，不能宣布H-BI成功，须依据结果另设计完整条件确认。
所有新拟合均保留并完成22条件评价，不能剔除失败种子，也不把未评价核心记为成功。旧六批不并入新K的二项区间。

## 固定样本与方法
96批；b=1..96：fit seed=2000001+100000*(b-1)，validation=fit+1。每批各5000图（各数量1000）、8000/2000平衡试次。核心301、编码器、原sigma及参考头冻结。eleven训练全部5–15时长22组，C=10000/tau=.005，四训练噪声，按每原试次总权重1、clean/noise各半、各时长等权。scaler每批重新以[5,7,10,13,15]的40000干净拟合状态构建。零初始化float64 Newton/Armijo，原梯度标准及独立审计不变。验证集不用于选择。
全部96头及训练审计完成、统一冻结后才生成640个共同新测试库，seed=20000100..20000739。每库1000图（各数量200）、2000平衡试次；10噪声重复先在库内平均。配对seed+10000，噪声和两种64次置换使用既定SeedSequence结构。间隔100000的拟合种子避免跨批派生配对流冲突。
新图总数1600000：训练/验证960000，测试640000；与已有1554000留存图及本轮图像去重，同数量拒绝重采样留痕。预期总留存3154000图。共同测试库仅是测量设计，不增加独立拟合样本数；任意跨头测量相关由联合覆盖处理。

## 统计、功效与停止
r=3，总alpha=.00625；measurement=rate=.003125。96×22=2112个测量区间，以640库、df639、双侧t、每项alpha=.003125/2112构造。22项全部下界>.85为S，任一上界<.85为F，否则U。以真实A成功数在[S,S+U]为基础，按原Clopper–Pearson公式计算q界，rate alpha=.003125。
至少32个确定失败使q上界<.80，因p≤q足以排除H-BI；否则主假设仍未决。即使q受支持也不是原p受支持。前3轮总预算≤.04375。不得将新96批与观察后选取的旧批次未经序贯设计直接合并。
样本量依据：在理想的真实失败均能分类情况下，q=.60/.65/.70时达到32失败阈值的二项功效约92.6%/67.0%/27.1%；真实测量可能出现U且共同测量相关，以上不是实际功效保证。640库参考第二轮方差，应缩小大多数条件误差，但边界极近的头仍可能未决。若U主导再登记精度实验；若已分类但概率界仍宽，再依据完整结果决定新增拟合或其他有明确价值的干预。不能因为96批完成而停止。

完整7040个核心×库×时长单元，(96×11+8)×640×11=7490560个候选/参考预测向量；独立从像素重建全部预测、噪声、原头、reset和置换。第二套聚合复算2112个区间、S/F/U及q界。质量失败先修复，不裁决主假设。
