# B-I 第四轮：冻结96次拟合的有序精度检验

## 前轮依据与目标
第三轮完整审计后，核心301全22条件事件A为S=28/F=21/U=47，q界[.1663452585,.8899954837]，原p≤q，仍未决。47个U中21个至少有一个条件点估计低于85%。继续新增拟合之前，优先减少现有96次拟合的测量不确定性。第三轮全部科学工件已封存；本轮无新拟合，K仍96，不混入旧六批。
第四轮rate alpha=.0015625，至少33个确定失败可使q上界<.80。因此需要在原21个F之外增加12个有控制的失败证书。原28个S与21个F依赖第三轮联合覆盖，保留不重算、不把旧测试库混入新均值。

## 固定靶点、次序和算法
对每个第三轮U，以第三轮未决条件中(.85-均值)/库级SD最大的条件作为候选，按该值降序取前12，次序与数值完整存于config.json、planning_diagnostics.json。次序为：55/11/noise，50/9/noise，40/15/clean，85/15/noise，3/9/noise，20/9/noise，37/9/noise，5/15/noise，65/11/noise，23/9/noise，11/15/clean，86/15/clean。
每个靶点属于一个不同的原U批次，排除其一个条件足以判该批301事件失败。该筛选只使用已完成第三轮数据，之后不改变次序或靶点。核心、sigma、12个头及所有原参考头完全冻结并逐参数审计；不得重拟合、调整85%或80%门槛。

## 新测量与分阶段规则
预先固定累计新库数1024、2048、4096、8192，最多四次查看。各阶段只生成此前尚未生成的新库；同轮累计测量在预登记固定查看点汇总。不是观察后把任意样本量代入未校正固定样本区间。
全局bank i的图像seed=30000100+i，i=0..8191；配对seed+10000，噪声SeedSequence([seed,20000,rep])、两种64次置换[seed,30000/40000,rep]不变。每库1000图、2000平衡试次、10次噪声在库内平均。全部图像与3154000张历史留存图和本轮先前新图去重，同数量原RNG拒绝重画留痕。最多8192000张新图，累计最多11346000张；未执行阶段不生成数据。
所有12头在每个新库的时长5、9、11、15及clean/全部10噪声均完整评价。主检验仅使用上述12个已选条件，其余候选输出是审计或描述数据，不临时挑选新主条件。正对照为5、11、15参考头及original5，合计8项99%库级区间下界>90%；所有候选及相应参考reset、64标签置换与64数量内行错配均值须47–53%。每阶段全部新增库、全部条件、原头、reset、噪声及置换均完成独立重建后才分析。

## 推断设计修订：固定次序检验与查看点花费
本轮是事前登记的科学推断修订：不沿用“每项Bonferroni双侧区间”的低效率分类；采用有证明的固定次序单侧检验。原假设、训练算法、阈值和跨轮总预算不变。measurement alpha=.0015625，四查看点比例[.10,.15,.25,.50]，实际单侧额度分别[.00015625,.000234375,.000390625,.00078125]。
第j次查看以该时点全部本轮新库计算每靶点U_j=mean+t.isf(alpha_j,N_j-1)*SD/sqrt(N_j)。检验H_i:该条件真实BA≥.85，仅当U_j<.85才可排除。按照冻结次序从尚未认证的第一个靶点开始，连续排除才延长已认证前缀；遇到第一个未排除项即停止延长，后面即使点估计或单项上界更低，也不记为确定失败。过去阶段已认证的前缀保留，不因新均值波动而撤销。所有12项的计算和原始输出仍完整保留。

错误控制证明：条件化于第三轮全部数据、冻结头及预定次序，若存在真实零假设，令i*是序列中第一个真实零假设。任何错误前缀证书必然包含i*，因此必然在某个预定查看点错误排除了H_i*。各固定查看点单侧检验错误率≤alpha_j，故不要求头之间或查看点之间独立，任意错误前缀的概率≤sum_j alpha_j=.0015625。不存在真实零假设时没有错误证书。这个结论针对有序前缀，不声称12个单项上界共同覆盖，也不允许跳过未排除靶点。

与原可靠性连接：在第三轮测量覆盖与本轮前缀正确事件上，真实96批301失败数至少21+prefix，成功数至少28。将保守S=28、F=21+prefix、U=47-prefix代入原Clopper–Pearson公式，rate alpha=.0015625，两端各alpha/2。这里只对固定96个原始拟合的同一个潜在真实成功总数使用一次二项覆盖事件；重复查看不断收紧的保守计数不产生新的拟合样本或额外的二项区间选择错误。每次查看得到的外包区间在该同一潜在CP覆盖事件及全部测量证书正确事件上均覆盖q。由p≤q，q上界<.80即可限定排除原H-BI。q下界仍不能支持原p。
前三轮加第四轮最大花费≤.046875。条件于固定核心、固定生成分布、近似IID及库级t覆盖的限制不变；图像全局去重有有限依赖、伪随机有限实现，不能把这套t近似称为无条件精确保证。序贯预算的逻辑是确定的，单次t覆盖仍是原方案的近似前提。

## 每阶段完成后怎样决定下一步
每阶段必须先完成数据审计、全部评价、独立预测重建、质量门槛和第二套统计复算。随后：
1. 若q上界<.80，达到原停止规则，结束B-I实验；不生成后续库。
2. 若未达到，另计算靶点的诊断性99%双侧区间；若尚未认证的某一靶点下界>.85，说明当前“这12项都能排除”的路线出现反向迹象，结束本轮精度路线，并依据完整结果另立下一轮。该诊断区间不作联合覆盖主张，也不支持原主假设或直接触发主分支停止。
3. 若未达到且没有该反向迹象，按事前登记的下一查看点增加精度，先记录上一阶段摘要哈希、理由、下一样本数和额度，再生成数据。
4. 第四查看点后仍未决则重新规划，不能因为8192库完成或耗时而宣布科学停止。
