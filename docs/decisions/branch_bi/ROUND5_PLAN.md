## 固定最大候选族与查看点
候选族是第三轮不可变round_summary.json中所有state=U批次的全部unresolved条件，精确为47个批次、68个条件。这个最大未决族完全由第四轮任何数据生成前的第三轮结果确定；不得根据第四轮成绩删减族、只计算喜欢的子集校正或增添其他条件。原S/F条件保留其既有证据，新增失败只来自这个完整未决族。
查看点族固定为[1024,2048,4096,8192]库，逐字对应第四轮在数据前冻结的look_sizes。第i个库的图像seed=30000100+i及所有原派生流也在第四轮前冻结，参数、头、任务、配对和噪声定义均未改变。未来若沿同一前缀继续，存储路径可以改变，但像素生成顺序、同数量去重、配对和噪声函数必须保持相同。首次补齐2048库，计算可用的1024与2048两个固定查看点；其余查看点不提前生成数据。

## 同时覆盖如何保护已查看数据的选择
第五轮measurement alpha=.00078125。每个条件、每个可能查看点的单侧错误额度delta=.00078125/(68*4)。以该固定查看点的库级均值和样本SD计算U=mean+t.isf(delta,N-1)*SD/sqrt(N)，库内10次噪声先平均。
条件化于第四轮前已冻结的第三轮数据及头，对固定68项和固定4个查看点，若每个单项t上界的覆盖错误≤delta，则联合界给出
P(存在任意条件/查看点上界低于其真实均值)≤68*4*delta=.00078125。
因此在该同时覆盖事件上，任何事后选择的条件子集、任何已经完成的查看点、或各条件取已有查看点上界的最小值，都仍是有效上界。无须条件之间或查看点之间独立。没有实际计算的未来查看点也包含在错误额度中；不得把这些额度另用于未登记的样本数。
本次先补齐完整最大候选族，并保存全部输出，不按已查看成绩缩小校正分母。数据暴露被显式计入选择问题，没有把普通单项CI当作选择后CI。以后也不能以本证明为依据任意改模型、族、试次数或查看点。
同时覆盖保护事后选择的一般统计思路可参见Berk等（2013）[Valid post-selection inference](https://arxiv.org/abs/1306.1059)及Kuchibhotla等（2018）[Valid Post-selection Inference in Assumption-lean Linear Regression](https://arxiv.org/abs/1806.04119)。这些文献讨论的具体回归模型并非本实验；本方案所用的有限族联合界证明如上，不能借文献声称本实验的t近似变成精确覆盖。

若某批至少一个族内条件在某个已完成查看点的上界<.85，可增加该批核心301失败证书。合并第三轮21个F、第四轮已合法获得的5个定序F及本轮证书时，按批次取集合并集；重复条件、重复查看和重复评价均不得增加K或重复计失败。S保留第三轮28个，不以新单侧上界确认新成功。其余仍为U。须完成当前查看点的全部68项评价、独立审计和第二套统计复算后才能判定。

## 复用原第三轮固定96次拟合的概率覆盖事件
本轮仍是完全相同的96次拟合和同一个事件A（301全部22项真实BA>.85）。令T为这96次拟合中潜在真实成功总数，未因新增测量或候选选择改变。第三轮已花费rate alpha=.003125，为q∈CP(T,.003125)提供二项覆盖。
若后续合法测量证书给出S≤T≤96−F，则由CP端点对成功数的单调性，区间[CP_lower(S),CP_upper(96−F)]包含该同一个潜在CP(T)区间。此包含关系同时适用于所有后续测量结果，故可复用原事件；不把同一批96次拟合重新当作新样本，也不需要为同一个潜在计数事件反复支付新的rate错误。
这里使用原第三轮两侧各.003125/2的CP端点。至少32个确定失败即可令q上界<.80。新增测量仍单独承担本轮同时覆盖错误；第四轮原数值区间及原alpha不改写，本轮单独记录这项证据综合。第五轮新的rate额度不使用。前三轮和第四轮的既有花费均保留，按原各轮最大额度保守相加，五轮仍≤.0484375<.05。
原五核心110项事件E蕴含同一301事件A，因此p≤q。q上界<.80可限定排除原H-BI；q下界不能当作p下界。本方案未改变85%或80%的科学门槛。
