# BN001：首轮执行细化（实验结果产生前）

用户已授权执行 B-N。科学阈值、固定敏感集合、20 个测试库及噪声尺度沿用初始协议，不更改。

- 将干净臂的八个重复状态合并为一个权重 1 的样本；增强臂的四个干净重复合并为权重 0.5，其余四个噪声样本各权重 0.125。两臂每原试次总权重均为 1。合并是精确目标函数等价的计算简化，执行前用小型逻辑回归验证。
- 拟合和验证增强分布均使用四个独立噪声实例，replicate=0..3；测试使用 0..9，因库 seed 不同，随机流独立。
- 数量探针在加噪后测试前和测试结束两个位置拟合，采用增强臂相同的 50/50 状态混合、每原试次总权重 1、C 网格与验证损失选择。各位置的标准化只拟合对应的干净拟合状态。
- 学习曲线使用按数量对分层截取的前 25%、50% 试次；各自标准化只拟合所用的干净状态；使用完整训练已选择的 C，不能依测试重新选择。100% 使用主要拟合。
- 20 库均评估所有已预定的噪声条件及10次扰动重复。负对照的状态错配／测试标签置换各64次，应用于第0次主噪声预测（行独立推理意味着置换状态与置换预测等价）；这些负对照先在每库内平均。清零状态测干净重置及主噪声重置。
- 数量探针的条件置换在测试数量 b 内置换样本数量标签，64次；保持联合频数，先在库内平均。探针主表现平均10次主噪声重复。保留匹配／不匹配子集表现。
- 负对照总体质量门槛同时覆盖两个新头和全部五模型。主要科学区间仍只针对预先指定三模型集合上的20个独立库，不能把参照模型混入主要统计来稀释效应。
- 程序必须支持测试库每数量200张，不能复用旧B脚本里硬编码1000的编码reshape。新实现要验证像素与缓存编码前向一致、干净续算一致、清零续算一致。
