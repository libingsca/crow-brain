# BN004：限定 H-BN1 获支持，结束首轮科学实验

全部五模型、20个新测试库、预定对照和诊断已完成。数值修正统一用于所有模型，原失败保留。独立审计通过。

主要集合固定为301、302、305。增强头主噪声 BA=0.975605，98⅓%图像库层区间[0.974987,0.976223]；相对新干净头提升0.394417，区间[0.393330,0.395503]；干净损失0.000108，区间[-0.000303,0.000520]。分别满足>0.80、>0.15、<0.02的预定区间判据。质量门槛全部通过。

因此按“限定假设获支持”停止本次科学分支，无需为了增加轮数再安排实验。BN002是同一首轮的优化修正，BN003是补齐已规划描述性参照，均不是新增科学假设轮次。

置信区间只覆盖固定模型与固定拟合头上的新图像／扰动采样，不覆盖随机模型群体或重新拟合。一次性状态噪声下的线性读出救援不等于吸引子、普遍稳健记忆、跨时间通用读出或真实NCL机制已被证明。

停止不是因为运行成本或信息价值低；新种子、持续噪声、统一时间读出等问题仍可能有价值，但需要另立目标和判据。本次无实验或监控进程遗留。
