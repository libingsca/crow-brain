# UC-H01 R1：开发协议（训练前冻结）
日期 2026-09-27。用户最新指令只先验证 H01，因此将原 H01×H02 首轮筛查收缩为 H01，在所有模型中固定使用 GRU 门控，不检验 H02。合成结构化任务，不是动物实验。

## 明确比较
S64：48 维内容 GRU（对象及保持/更新提示输入）＋16 维规则 GRU（末尾问题输入），拼接后 32 维 tanh 读出。F64：融合 GRU64＋同形式读出。FP：融合 GRU51＋同形式读出。S64=13474 参数，FP=13511（差 0.275%）；F64=19426，提供同总状态量的较强容量对照。两个比较分别控制参数和状态，不能声称同时完全匹配。分区是输入与循环通路分离，不给予额外真值；候选与基线都用可训练 GRU，表示范数不作特殊处理。

## 任务与划分
16 个颜色×形状对象，排除颜色索引=形状索引的4种对象组合用于训练。每次两个对象同时输入；位置为左右两槽的随机交换。记录字段为初始样本对ID、候选样本对ID、更新提示、最终规则、延迟、两次位置翻转。t0样本，t1保持/更新，t2候选样本，2/4/6空白步，最后颜色相同/形状相同问题。训练使用最终是/否监督。

按更新×问题×相关样本颜色相同×形状相同16组精确平衡。无关样本由独立随机关系生成；更新时候选本身是有效证据，因此“候选单独不能预测答案”只在保持试次适用。ID相关样本全为训练对象；OOD相关样本至少包含一个留出对象，无关样本仍来自训练对象。该 OOD 是未见属性组合，不是从未见过属性，也不是额外的规则组合留出；结论限制于此前定义的这一子类。

有限任务无尽独立完整实例不可能。用完整7元记录的单射整数编码与固定 splitmix64 散列，桶0–7训练、8验证、9测试，保证三者无完整记录重合；各集合内允许重采样，明确不是无限语义新实例。训练过的属性对可以在新的完整上下文中出现。延迟8是单列次指标。16组合平衡不保证每一无关属性边际完全独立；需另做单对象、位置、提示、保持试次干扰物的捷径审计。

## 开发规模及保存
每模型学习率0.001/0.003，seed270101–270105，每次2000步、batch64、Adam默认beta/epsilon、梯度范数裁剪1。5×2×3=30训练。各模型用相同seed的相同训练记录。按5seed平均ID验证交叉熵选学习率；不用OOD选。每个条件4096平衡试次，保存完整记录、标签、logits、reset预测及每个训练batch。末尾问题前全状态清空为记忆负对照。权重只取终点。
